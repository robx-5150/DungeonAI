# DungeonAI

A Dungeon Keeper-inspired visual reskin of the StarNet AI system. Phase 1 is a frontend remodel — the underlying StarNet functionality stays intact while the interface transforms into a living, interactive dark-fantasy dungeon.

## Project Structure

- `frontend/dungeon/` — The Dungeon Heart interface (main UI)
- `docs/` — Character mapping and design docs
- `src/` — Shared utilities and helpers
